Ejercicio 6

Analizar este código:

const mensaje = "Mensaje global";

function primeraFuncion() {
    const mensaje = "Mensaje local";

    function segundaFuncion() {
        console.log(mensaje);
    }

    segundaFuncion();
}

primeraFuncion();

console.log(mensaje);

Sin ejecutar el código, indicar qué se imprime y explicar por qué.

Parte 4 – Funciones llamadoras
Ejercicio 9 – Conversor

Crear tres funciones:

aKilometros(millas)
aMillas(kilometros)
aMetros(kilometros)

Todas deben retornar el resultado de la conversión.

Después crear:

convertir(valor, funcionConversion)

La función convertir() debe recibir:

un valor
una función

y debe encargarse de llamar a la función recibida.

Ejemplo:

convertir(10, aKilometros);
convertir(10, aMillas);
