div -> Division, es la forma mas generalista de crear una Division
header -> Es el encabaezado de la pagina, representa contenido introductorio 
nav -> Es la seccion de navegacion de la pagina.
main -> Es la seccion que contiene el contenido principal, generalmente existe uno unico
footer -> Es el pie de pagina

section -> Agrupa contenido relacionado
article -> representa contenido independiente, se puede usar para noticias, publicaciones, posts
            productos, comentarios, articulos de un blog. }
aside -> contenido relacionado pero seucndario, como por ejemplo un sidebar, publicidad, contenido relacionado
        enlaces adicionales, etc.


ETIQUETAS DE TEXTO.

<h1> ... <h6> -> Etiquetas de Headings, sirven como "titulos", el h6 es el mas chico
<p> -> Parrafo
<span> -> Contenedor en linea, que sirve para agrupar fragmentos de texto y aplicarles estilos diferentes
<br> -> salto de linea
<hr> -> Salto tematico (Casi no se usa)
