Que es un bucle?
Un bucle permite repetir un bloque de codigo varias veces sinb tener que escribirlo
manualmente

Es como si dijeras -> Hace esto X veces

Por ejemplo:
console.log("Hola")
console.log("Hola")
console.log("Hola")
console.log("Hola")
console.log("Hola")

Podemos hacerlo con:

for(let i = 0; i < 5; i++){
    console.log("Hola")
}

La idea fundamental es:

Mientras se cumpla X condicion, repetimos codigo.

¿Para que sirven los bucles?

Algunos ejemplos reales:
-Mostrar numeros del 1 al 100
-Recorrer una lista de productos para aplicar un descuento/aumento
-Mostrar los nombres de los alumnos
-Calcular un total
-Buscar un elemento
-Repetir una operacion determinada cantidad de veces
-Procesar informacion de un array

El bucle for:
Es el bucle mas usado, y el principal para aprender.

Sintaxis:

for (inicio; condicion; incremento){
    Codigo que se repite
}

ejemplo:
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

Resultado:
1
2
3
4
5

1 - INICIO:
for (let i = 1; i <= 5; i++) {
    console.log(i);
}

let i = 1
Creamos una variable i y empezamos en 1

2 - CONDICION:
i <= 5
Mientras esto sea true, el bucle continua

3 - INCREMENTO 
i++
Despues de cada vuelta, aumentamos i en 1

--------------------------------------------

EJEMPLO parte por parte:
for (let i = 1; i <= 3; i++) {
    console.log("Hola");
}

i = 1 (INICIO)
¿1 <= 3? True (CONDICION)
console.log("Hola")
i = 1 + 1 = 2 (INCREMENTO)
¿2 <= 3? True (Condicion)
console.log("Hola")
i = 2 + 1 = 3 (INCREMENTO)
¿3 <= 3? True (CONDICION)
console.log("Hola")
i = 3 + 1 = 4 (INCREMENTO)
¿4 <= 3? False (CONDICION) -> Deja de ejecutarse

--------------------------

i++ es lo mismo que i + 1

i-- es lo mismoq ue i - 1

-------------------------

Bucle WHILE:

while(condicion){
    codigo
}

ejemplo:
let i = 1;

while (i <= 5){
    console.log(i)
    i++
}

Diferencia entre for y while:

for -> Lo usamos cuando sabemos cuantas veces queremos repetir algo (en general)

while -> Es util cuando queremos repetir algo mientras se cumpla una condicion

----- MUY IMPORTANTE ------

Bucles infinitos:

let i = 1;

while (i <= 5){
    console.log(i)
}

Esto nunca termina, porque la condicion sera eternamente true, porque i no cambia

Todo While debe tener alguna forma de llegar eventualmente al false.

---------------------------------------------------

BUCLE DO WHILE

do {
    codigo
} while (condicion)

La diferencia con while?
while pregunta, y luego ejecuta
do while ejecuta y luego pregunta, por ende se ejecuta MINIMO 1 vez

----------------------------------
BREAK Y CONTINUE:
Break -> Sirve para "romper" el bucle inmediatamente.

for(let i = 1; i <= 10; i++){
    if (i === 5){
        break;
    }
    console.log(i)
}

CONTINUE -> Hace algo diferente
No termina el bucle.
Salta esa vuelta, y continua con la siguiente:

if(let i = 1; i <= 5; i++){
    if(i === 3){
        continue
    }

    console.log(i)
}
